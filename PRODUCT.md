# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Pessoa física organizando as próprias finanças.

## Product Purpose

O Economize ajuda a pessoa a registrar e controlar receitas, despesas, contas,
categorias, recorrências e transferências para obter mais clareza sobre seus
gastos e apoiar o planejamento financeiro.

## Capabilities and Constraints

- A aplicação usa português brasileiro na interface.
- A API de autenticação estabelece a sessão por cookie HTTP-only.
- O frontend usa o Ky para chamadas à API e deve incluir credenciais nas requisições.
- Respostas de erro da API seguem RFC 9457.
- A interface deve funcionar em dispositivos móveis e computadores.

## Brand Commitments

- O nome do produto é Economize.
- A comunicação do produto deve ser clara, direta e orientada à consciência financeira.

## Product Principles

- Tornar os gastos mais fáceis de entender.
- Apoiar decisões financeiras conscientes.
- Priorizar uma experiência simples para o registro cotidiano.
- Funcionar bem em diferentes tamanhos de tela.

## Accessibility & Inclusion

- A interface deve ser responsiva e mobile-first.
- Formulários devem funcionar com teclado, manter foco visível e associar mensagens de erro aos campos.
- A interface deve respeitar a preferência de redução de movimento do sistema.
