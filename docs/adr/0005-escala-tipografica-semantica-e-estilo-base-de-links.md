# Escala tipográfica semântica e estilo base de links

## Status

Aceito

## Decisão

A interface adota papéis tipográficos semânticos compartilhados para manter a hierarquia visual consistente entre telas. Botões e links compartilham o contrato de estilos, incluindo a tipografia base da variante `link`, para que sua aparência evolua em conjunto.

As regras de uso e a referência ao catálogo ficam no [guia de interface](../agent-guidelines/ui-and-styling.md#tipografia).

## Consequências

- Mudanças na tipografia base de `Button` também podem afetar links, pois ambos compartilham a mesma variante visual.
