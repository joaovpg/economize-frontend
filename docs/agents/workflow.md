# Contexto e documentação

Carregue somente a fonte de contexto relacionada ao escopo da tarefa.

## Roteamento de contexto

- Para terminologia de domínio ou decisões arquiteturais, siga o [guia de documentação de domínio](domain.md).
- Para comportamento, escopo, API, responsividade ou acessibilidade do produto, leia `PRODUCT.md`.
- Para aparência, layout, tipografia, cores ou componentes visuais, leia `DESIGN.md`.
- Para issues ou especificações locais, siga o [guia do issue tracker](issue-tracker.md) e use somente os estados descritos no [guia de rótulos](triage-labels.md).
